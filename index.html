Responsibility drift

Arrangements tuned for capability but weak on tracing should show responsibility drift under perturbation: the gap between what the human is held answerable for and what the human actually contributed widens. This is Proposition P3 of the scoping review, which proposes testing it with and without logged reallocation events.

What this simulator implements, and what it adds

From the paper. Context vector (1); strength score (2) as a weighted geometric mean with 00 = 1; Δ (3); admissibility constraints (4)–(7); the compact rule; the published transition rule line by line; responsibility (9)–(12) with the ψ fallback for a zero denominator; reference weights, thresholds and exponents.

Policy modes. The paper's compact rule and its published rule differ, and the published rule can return a state its own constraints exclude:

  • Line 6 returns SH→M without checking (7), so a time-critical case with a machine advantage enters an excluded handover state.
  • Line 16 returns SN without checking (7), so a time-critical, ambiguous case enters excluded negotiation.
  • Line 3 forces SH under override even though (4) also admits SHM and SM→H.
  • The compact rule jumps straight to SM and is stateless; the published rule depends on qt and passes through the handover states.

Behaviour of the published rule that the simulator exposes (see the transition map on the Rollout tab):

  • SN is nearly absorbing. From negotiation, a clear human advantage (Δ ≤ −θH) or machine advantage (Δ ≥ θM) leaves the state at SN; only |Δ| < ε (to SHM) or line 3 (to SH) leaves it. “Recovery” has no rule of its own.
  • SHM has no direct exit to SH or SM: any clear advantage sends it to SN, where it then stays.
  • An interrupted handover does not reverse: SH→M with a human advantage, and SM→H with a machine advantage, both go to SN.
  • On 200,000 random contexts, the published rule returned an excluded state in 8.2 % of cases (compact rule: 3.1 %), and the two policies disagreed in 25.3 %.

Admissibility-preserving rule. A proposed correction that keeps the paper's states, inputs, constraints and thresholds, and changes only the transition rule:

  • Every branch checks A(xt), so the result is always admissible (0 violations in 400,000 random contexts).
  • A clear machine advantage (Δ ≥ θM) starts a handover from any non-machine state, including SHM and SN; a clear human advantage (Δ ≤ −θH) returns any non-machine state to SH. Negotiation and shared control can therefore always be left.
  • An interrupted transfer reverses: SH→M with a human advantage returns to SH; SM→H with a machine advantage returns to SM.
  • When TC ≥ κ excludes the handover states, a transfer is made directly (lines 8 and 11) instead of entering an excluded state.
  • An override, ethical-risk or fairness trigger in machine-led control passes through the logged return SM→H when it is admissible, so the most safety-relevant transfer is also visible.
  • When no allocation rule applies, the paper's choice (SN) is kept by default. The alternative “hold” keeps a stable state instead, which treats the gap between ε and θ as a hysteresis band.

On the 100 scenarios, the admissibility-preserving rule with the default setting gives the paper's 26 / 45 / 28 / 1 exactly, because every case starts in SH and none reaches a changed branch. With “hold”, the 28 negotiation cases become human-led (54 / 45 / 0 / 1).

“Human fallback” keeps the published rule but replaces any excluded result with SH, which (4)–(7) never exclude. It is one possible repair, not the paper's rule.

Added for the Responsibility and Responsibility drift tabs (not in the paper).

  • Regime presets for χ, a, k, f and d. The paper reports machine responsibility of 23.3 %, which requires dM > 0 and fM > 0, so the presets keep both small but non-zero.
  • Responsibility drift outcome model: yt = ψH·CPH + ψM·CPMtrue + ψG·mean(CPH, CPMtrue).
  • Silent drop: true machine capability falls at the onset; the model's observed CPM follows only after the detection lag.
  • Latency spike: TC is raised for the window and the human's capability falls by the stated loss, both visible to the model.
  • Without a handover log, transfers skip SH→M and SM→H, and the accountability record (normative factors) lags the actual regime by one epoch, while functional shares follow the actual regime.

Scenario validation. The Scenario replay tab runs the 100 cases from scenario_analysis_support.py. With paper defaults it matches the notebook in all 100 one-step and stable states, and in strengths and responsibility shares to within 10−10. Three properties of that mapping matter for the paper:

  • Responsibility inputs are built from family profiles and keywords only, never from the selected state, so in the validation responsibility is not coupled to the authority regime.
  • By construction TC cannot exceed 0.50 (κ = 0.80), ER reaches at most 0.545 in the corpus (ρ = 0.70), and VAHM never falls below τ, so constraints (5, ethical-risk part), (6) and (7) are never exercised.
  • 16 of the 26 human-led outcomes come from line 3, triggered by the keyword flags HO (“override”, “veto”, …) and FC (“bias”, “neighborhood”, …); only 10 come from a human strength advantage.
